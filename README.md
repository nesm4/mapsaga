
# MapSaga



Projet de programmation développé en Python. MapSaga est un générateur de cartes et un jeu s'appuyant sur le module graphique FLTK (`fltk.py`).



## Fonctionnalités



* Génération et édition de cartes avec plusieurs types de tuiles (mer, ville, terres)

* Interface graphique gérée avec FLTK

* Intégration de décors, sprites et écrans de menu



## Structure du projet



* `mapmaker.py` : Script principal du jeu et du générateur de cartes

* `fltk.py` : Module d'interface graphique

* `decors/` : Tuiles et éléments de décor (dossiers `mer/` et `terre/`)

* `*.png` : Images de l'interface et des entités



## Lancement



1. Cloner le dépôt :

   ```bash

   git clone https://github.com/nesm4/mapsaga.git

   cd mapsaga

   ```



2. Lancer le script principal :

   ```bash

   python mapmaker.py

   ```
